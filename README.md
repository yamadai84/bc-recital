# Be Color 発表会 イベントページ

スプレッドシートを編集すると、Webページに自動で反映されるイベントページです。

```
スプレッドシート ──(GAS: Webアプリ)──> JSON ──> GitHub Pages の index.html が表示
```

- ページ本体（`index.html`）は GitHub Pages で公開
- 内容はスプレッドシートで管理。GAS が JSON にしてページに渡す
- パスワード付きボタンは、GAS 側でパスワードを照合してから URL を返す（ページのソースを見ても URL・パスワードは分からない）

---

## セットアップ（最初の1回だけ）

### 1. スプレッドシートと GAS

1. Google スプレッドシートを新規作成（名前は自由）
2. メニュー「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身を全部消して、`gas/Code.gs` の内容を貼り付けて保存
4. 上部の関数選択で `setupSheets` を選んで「実行」→ 権限の許可を求められたら許可
   - 「設定」「項目」シートが、今の lit.link（becolorrecital）と同じ内容で作られます
5. 右上「デプロイ」→「新しいデプロイ」
   - 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/.../exec`）をコピー

### 2. GitHub Pages

1. GitHub で新しいリポジトリを作成（例：`bc-recital`、Public）
2. `index.html` を開き、上の方の次の行に手順1-6の URL を貼り付ける

   ```js
   const GAS_URL = 'https://script.google.com/macros/s/XXXXXXXXXXXXXXXX/exec';
   ```

3. `index.html` をリポジトリにアップロード（「Add file」→「Upload files」）
4. リポジトリの「Settings」→「Pages」→ Branch を `main` / `/(root)` にして Save（`/docs` だと「File not found」になります）
5. 1〜2分後、`https://<ユーザー名>.github.io/bc-recital/` で公開されます

> ロゴ・favicon は「設定」シートの「ロゴ画像URL」（空なら lit.link のイベントロゴ）を使うので、画像ファイルのアップロードは不要です。

## 普段の更新方法

スプレッドシートを編集するだけです。ページを再読み込みすると反映されます。
（反映されないときは、スプシのメニュー「Webページ」→「今すぐ反映する」）

### 「設定」シート

| 項目 | 内容 |
|---|---|
| ページタイトル | ヘッダー（ロゴの横）に出る名前 |
| バッジ | ヘッダー右の小さいラベル（スマホでは非表示） |
| ロゴ画像URL | ヘッダー・フッターの丸いロゴと、ブラウザのタブのアイコン。空なら lit.link のイベントロゴを使用。GitHub に画像を置いたら `event-logo.jpg` のようにファイル名を書く |
| サブタイトル | 緑のイベントカード上部の小さい英字など |
| イベント名 / 開催日 / 会場 | 緑のイベントカードに表示。開催日を「2026年11月7日(土)」の形で書くと「あと○日」が自動で出ます |
| ひとこと | イベントカード下部の補足文（空なら非表示）。文章ルールが使えます |
| テーマ色 | `#0047b9`（青）。変えると全体の色が変わります |

### 「項目」シート（上から順に表示）

| 列 | 内容 |
|---|---|
| 表示 | チェックを外すと非表示（下書き・公開前の準備に） |
| 種類 | `見出し` / `リンク` / `文章` / `画像` |
| タイトル | 見出しの文字、またはカードの太字部分 |
| 説明・文章 | リンクなら小さい説明文、文章ならその本文 |
| URL | リンク先（空なら押せないカードとして表示＝「随時更新します」などに）。`画像` のときは画像のURL（Google ドライブの共有リンクも可。ファイルは「リンクを知っている全員」に共有） |
| アイコン | 絵文字（📖 🎧 ✏️ 🎫 📍 など） |
| パスワード | **入れるとパスワード付きボタンになる**。空ならふつうのリンク |

- `見出し` ごとにセクションが分かれ、ページ上部に目次ボタンが自動で並びます
- 並べ替えは行ごと移動、追加は行を挿入するだけです

#### 文章の書き方（`文章` と「ひとこと」で使えます）

- セル内で改行（Mac：⌘+Enter／Windows：Ctrl+Enter）すると、そのまま改行されます
- `https://...` と書くと自動でリンクになります
- `**ここを強調**` のように `**` で囲むと太字（緑色）になります

### 生徒限定ページ（パスワード付き）

1. 「項目」シートで種類 `リンク` の行の「パスワード」列にパスワードを入れる
2. ページ上では 🔒 付きのボタンになり、押すとパスワード入力画面が出ます
3. 正しいパスワードを入れると「ページを開く」ボタンが表示されます

- パスワードはボタンごとに別々に設定できます。変更もスプシを書き換えるだけで即反映
- 一度解除すると、そのタブを閉じるまでは再入力不要です
- 例として「【生徒限定】出演者向け資料」という非表示の行（パスワード `becolor2026`）を入れてあります。使うときは URL・パスワードを変更して「表示」にチェック

#### 注意（大事）

このパスワードは「ページ上のボタンから URL を知られない」ための仕組みです。リンク先の URL 自体を知っている人は直接開けてしまいます。

- リンク先の Google ドライブ等は「リンクを知っている全員」共有のままで動きますが、URL を生徒が外部に転送すると見られてしまいます
- より厳しくしたい資料は、パスワードを定期的に変える／イベント後に共有を停止する、などで運用してください
- スプレッドシートにパスワードが書かれるので、スプシの共有は運営スタッフだけにしてください

## GAS のコードを変更したとき

スプシの**内容**を変えるだけなら再デプロイ不要です。
`Code.gs` 自体を書き換えたときだけ、「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」で更新してください（URL は変わりません）。
